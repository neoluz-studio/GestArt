# GestArt 1.0

GestArt es una plataforma SaaS multiempresa configurable para administrar
clientes, presupuestos, pedidos, producción, materiales, inventario, caja,
historial, reportes, usuarios y documentos.

## Estado

Esta carpeta corresponde al cierre de la **Etapa 14** y a la primera versión
integral del proyecto.

## Stack

- Next.js
- React
- TypeScript
- Supabase / PostgreSQL
- Auth + RLS
- jsPDF

## Instalación

Conservar `.env.local` y ejecutar:

```bash
npm install
npm run dev
```

## Comprobación técnica

```bash
npm run check
```

## Supabase

Si la base ya tiene las etapas anteriores, ejecutar solamente:

`supabase/migrations/0012_final_hardening.sql`
